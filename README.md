# 历史的经纬

Svelte 5 + TypeScript + Canvas 动态历史星河，精选展示 1818—2000 年间 24 位人物、32 部文献与 37 个事件。

## 开发

需要 Node.js 22.12 或更新版本。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:4173 。开发服务支持热更新。

```sh
npm run check   # Svelte 与 TypeScript 检查
npm test        # 历史数据、作者关系、轨迹交汇测试
npm run build   # 生成 dist 静态站点
npm run preview # 本地预览构建结果
```

## 使用

- 自动播放星河，支持暂停、1× / 3× / 8× 速度和拖动时间滑块。
- 人物轨迹从左向右展开，共同写作与明确共同参与关系在星点交汇。
- 点击星点、人物按钮、文献卡片查看详情；目录支持按书名与作者搜索。
- 70 年跟随视野与 1818—2000 全景切换；支持世界背景、中国脉络与苏联脉络筛选。
- 人物生卒与事件起止年表可展开；系统减少动态效果时不自动播放。

## 结构

- `src/App.svelte`：时间、选择项和筛选状态，以及动画生命周期。
- `src/components/Player.svelte`：播放、速度和时间控制。
- `src/components/Detail.svelte`：人物、事件和文献详情及过渡。
- `src/components/Library.svelte`：文献检索和卡片。
- `src/history.ts`：历史条目类型与显示辅助函数。
- `galaxy.js`：独立 Canvas 绘图模块与轨迹计算。逐帧绘图直接读取状态，退出组件时释放观察器和星点按钮。
- `data.js`：人物、事件、文献及明确参与关系。日期为公历，保留年/月/日精度。文献通常以写作完成时间定位，首次发表单列；交汇不表示实际会面或思想完全一致。

## 交互与资料

- 文献、事件、人物图例独立开关，切换后按当前地区和显示内容的最早节点重新播放。
- 年份线可拖动，跟随视野到边缘后自动平移，范围为 1818—2000；方向键调整 1 年，Shift 调整 10 年，Home/End 跳至两端。
- 日期文字直接跳转并暂停，超出展示范围的完整日期保留，跳转停在 2000 年。
- 底部人物索引支持折叠及姓名/角色搜索，收起索引时画布增高。折叠箭头与索引标题合并，不支持自由调整画布大小。
- 自动导览每十年按编辑优先级选一份资料，至少展示六秒；手动点选固定资料，点击“跟随播放”解除。
- 全部人物有历史结局及出处。历史评价与事实分栏，毛泽东、刘少奇、彭德怀依据 1981 年历史决议，邓小平依据中央党史和文献研究院资料。

中国脉络包括 11 位人物、15 个事件、8 部文献，包含古田会议、遵义会议、瓦窑堡会议、中共七大、七届二中全会、中共八大、反右运动、庐山会议和七千人大会等。角色区分主持、报告、与会及受迫害等不同关系。苏联脉络包括 9 位人物、19 个事件、14 部文献，也收录苏俄时期及相关人物早期文献。

`catalog.json` 只保存公开书目与阅读链接：24 条已核实豆瓣参考版本、8 条待核实、19 条微信读书入口（含文集）；其余为安娜的图书馆检索入口。参考版本、阅读平台版本和作品首次发表日期分别标明。密钥放在忽略的 `.env.local` 中，不得提交或编入前端；原始接口回包保存在忽略的 `work/` 中。

`china-events.js` 保存补充会议与角色，`outcomes.js` 保存历史结局和评价出处，`highlights.js` 配置自动导览优先级，`timeline-pan.js` 处理拖动边缘平移。
